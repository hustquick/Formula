Formula 1.5.0 修复源码模式的 LaTeX / Typst 切换。

- 修复启动时公式模板封面误出现在窗口底部的问题，模板只在对应标签下显示。
- 合并重复的输入与输出设置，统一放置于预览下方，保留字体、字号、A+/A−、颜色、留白、透明背景和 DPI。
- 全面审计快捷与模板微分符号，统一物理模板的导数、场微分和线面积分为正体 d，保留普通变量及 I_d 下标。
- 常用符号面板统一使用英文算子名称（优先 LaTeX 命令名）。
- 分类封面采用完整单行公式并适配按钮尺寸；根式角标空参数预览补充可见示例。
- 更新代数、不等式、微积分、矩阵、物理与化学分类封面；积分分类更名为微积分，微分符号 d 使用正体，不等式采用 leqslant。
- 修复全部十个快捷工具面板在排版引擎延迟启动时预览停留于“…”的问题，并使用有效名称替代缺失的“—”标签。
- SVG 按钮改为普通样式并省略“导出”，彩色强调移至“复制图片”。
- PNG 分辨率改为 72、96、150、300、600、1200 DPI，实际像素与 PNG 密度信息同步；兼容旧倍率设置。
- 启用离线化学排版扩展，并保留化学表达式空格，修复离子、反应箭头和沉淀符号输出。
- 可视化模式下禁用并灰显 LaTeX / Typst 按钮。
- 字体菜单在快捷工具、模板和收藏标签下均可使用；源码模式支持选中内容或整条公式的字体设置。
- 增加 A+ / A− 按钮，每次调整 2 pt，范围 10–160 pt。
- 未编辑时切回 LaTeX 保留原始源码，避免反向转换造成丢失。
- 切换时同步保存语言与源码，并修复旧版保存的不一致状态。

Formula 1.4.0 在 macOS 增加文档公式识别。

Windows 便携版同步版本号；本地 OCR 与 PDF/Word 公式识别目前仅在 macOS 提供。

- PDF 按页识别，支持页码范围；每次最多 20 页，未处理范围明确提示。
- Word `.docx` 提取原生公式，并识别内嵌图片中的公式，结果保留文档顺序。
- 独立安装 Word 解析组件，基础/专业 OCR 环境保持隔离。
- 按页码、段落展示可勾选预览，沿用勾选同步编辑器。
- 支持取消正在执行的文档识别，并清理临时文件。
- 加密/损坏文件、无效页码、外部图片链接给出明确提示。

文档识别只提取公式，不转换正文或原文档版式。旧 `.doc` 需另存为 `.docx`。真实验证记录见 PR；未验证 Intel 实机、macOS 12 实机或大规模准确率。

Formula 1.3.0 为 macOS 增加分级本地识别与整页公式提取。

- 基础识别使用 Pix2Text + MFD，专业识别增加 UniMERNet Tiny。
- 专业版先完成基础识别，再在独立 Python 环境中安装；基础识别在专业版下载期间仍可使用。
- 整页图片只检测公式区域；结果显示公式预览，勾选即同步，取消即移除。
- 安装优先选择 Python 3.11，支持 3.10–3.12；固定兼容依赖并执行 pip check 和真实模型初始化。
- 实时显示安装阶段、当前下载步骤进度与日志。取消会结束下载及子进程，清理未启用的环境和本应用模型目录中的未完成文件。
- 验证通过后切换独立环境；安装或修复失败保留原来可用的环境与就绪标记。
- 专业版整页识别通过基础版 Python 执行 MFD，避免两个识别器的依赖冲突。

当前本地识别针对图片，不包含 PDF/Word 文档识别。通用应用包含 Apple Silicon 与 Intel 二进制；Intel 运行效果需在 Intel Mac 验证。应用使用临时签名，尚未 Apple 公证。
