# Formula 1.6.0

本次较大版本更新集中改善源码编辑、结构变换与 OCR 工作流。

## 编辑

- 主界面统一为右侧“可视化 / LaTeX / Typst”三选一，移除“源码”层级及日常排版引擎选择。
- 内置优先排版；只有明确的能力限制才提示用户主动尝试对应本机环境，保留路径配置与旧配置迁移。
- 增加 LaTeX / Typst 补全、多候选、模糊匹配、光标处 ghost、环境闭合匹配、语法着色、括号提示、缩进与查找替换。
- 统一软件生成源码的格式规范：简单结构紧凑，复杂结构分层缩进，保留手动编辑。
- 修复选区在重音、上下标和结构包装时丢失；统一命令、Undo / Redo、macOS 菜单与快捷键。
- 分离历史公式与版本历史；保留最后有效预览并修复高公式裁切。

## OCR 与输出

- 支持剪贴板图片、拖入图片及选择文件后自动识别，普通文本粘贴不受影响。
- 图片和文档识别统一为结果优先布局；最右侧竖向微型工具区显示选择按钮、2 px 进度线及缩略图 / 中间省略的文件名。
- 模块、识别方式和安装操作集中到“设置 → 高级 → OCR 模块”，技术信息与日志退出主工作区。
- 统一字号与复制 / 导出控件，分辨率仅作用于位图输出。
- 保持正式 Bundle Identifier、已有用户数据与有效 OCR 模型兼容；本机安装支持备份与安全替换。

## 安装与限制

下载 `Formula-1.6.2.dmg`，将 Formula.app 拖到 Applications。通用应用支持 Apple Silicon / Intel，要求 macOS 12 或更新版本。

发布包采用临时签名，尚未 Apple 开发者公证。LaTeX / Typst 转换尚非完整语言级转换；遇到不支持的结构保留原文并提示。图形剪贴板不代表 Office 原生可编辑公式，WPS 兼容性仍需进一步实测。识别模型按需安装，不包含在 DMG 中。
